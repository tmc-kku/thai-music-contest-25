# วิธีประกาศผลหลังการแข่งขัน

1. ใส่ผลประเภทวงลงใน `data/results.json` และผลประเภทเดี่ยวลงใน `data/solo-results.json`
2. ตรวจชื่อ โรงเรียน รางวัล และวันที่ประกาศผลให้เรียบร้อย
3. เปิดไฟล์ `data/result-status.json` แล้วเปลี่ยนเฉพาะประเภทที่พร้อมประกาศจาก `"isPublished": false` เป็น `"isPublished": true`
4. หากเกียรติบัตรพร้อมดาวน์โหลด ให้เปลี่ยน `certificate.isAvailable` เป็น `true` และใส่ลิงก์จริงใน `certificate.url`
5. รัน `npm run build` แล้ว deploy เว็บไซต์

อย่าเปิด `isPublished` ก่อนใส่ผลชุดใหม่ เพราะข้อมูลเก่าที่ยังอยู่ในไฟล์ผลการประกวดอาจถูกแสดงบนเว็บไซต์ได้
